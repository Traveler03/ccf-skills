# CCF Skills

Personal CCFA skill collection for Codex.

This repository contains the current `ccf-*` skill baseline plus user-specific iterations. Install individual skills by pointing Codex's skill installer at the relevant path, for example:

```text
Traveler03/ccf-skills path: skills/ccf-paper-reader
```

## Current Additions

- `ccf-paper-reader`: Read one paper or PDF into a Chinese-first structured research note, including problem, gap, insight, method, Introduction translation, methodology figure explanation, experiment summary, limitations, and action items.

## Layout

```text
skills/
  ccf-common/
  ccf-literature-searcher/
  ccf-paper-reader/
  ...
```

## Privacy Note

Do not commit private manuscripts, unpublished results, credentials, or machine-specific local paths. Keep public-repo notes based on public papers, public benchmarks, and public project pages.
